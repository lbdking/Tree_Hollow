## Step 3 · 初始化 + 启动 MySQL & Redis

### 🍎 macOS

```bash
# 初始化 MySQL 数据目录（首次必做，已初始化过会报错可忽略）
/opt/homebrew/opt/mysql/bin/mysqld --initialize-insecure \
  --user=$(whoami) \
  --basedir=/opt/homebrew/opt/mysql \
  --datadir=/opt/homebrew/var/mysql 2>&1 | tail -5

# 后台启动（推荐 brew services；若无 LaunchAgents 权限用方式 B）
brew services start mysql || \
  /opt/homebrew/opt/mysql/bin/mysqld_safe --datadir=/opt/homebrew/var/mysql &

brew services start redis || \
  /opt/homebrew/opt/redis/bin/redis-server /opt/homebrew/etc/redis.conf &
```

### 🪟 Windows

MySQL 安装时一般已自动注册为 Windows 服务并启动。手动控制：

```powershell
# MySQL
net start MySQL80      # 服务名一般是 MySQL80 或 MySQL
# Redis（Memurai）
net start Memurai
```

### 🐧 Linux

```bash
sudo systemctl enable --now mysql redis-server
```

**【验收】**：
```bash
# 不论平台
mysql -u root -e "SELECT 1"      # 输出 1
redis-cli ping                     # 输出 PONG
```

## Step 5 · 后端启动（FastAPI）

### 5.1 创建虚拟环境 + 装依赖

#### 🍎 macOS / 🐧 Linux

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

#### 🪟 Windows（PowerShell）

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> ⚠️ 若执行策略报错，先运行：`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`

### 5.2 配置 .env（关键）

`.env` 已在仓库里，**只需要把 `DEEPSEEK_API_KEY` 替换为真实 key**：

1. 打开 https://platform.deepseek.com → API Keys → 创建一个 key（sk- 开头）
2. 编辑 [backend/.env](file:///Users/bytedance/my_project/agi/Tree_Hollow/backend/.env)，找到这一行：
   ```env
   DEEPSEEK_API_KEY=sk-请-在-这-里-填-你-自-己-的-DeepSeek-Key
   ```
3. 替换成自己的 key（sk- 开头的真实字符串），保存

> 💡 没有 DeepSeek key 也能跑，只是 AI 聊天功能不可用，其它功能（树洞 / 科普 / 预约 / 知识库 / 后台等）都正常。

### 5.3 灌入测试数据（**首次必做，否则没账号能登**）

```bash
# 在 backend 目录、虚拟环境激活状态下
python seed.py
```

**【验收】** 输出包含：
```

默认账号：
  管理员    admin / admin123
  ...
```

### 5.4 启动后端（**新建后台终端**，不要阻塞主对话）

```bash

uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## � 异常处理（Trae 遇到这些情况按方案应对）

| 现象 | 原因 | 处理方案 |
|---|---|---|
| `pip install` 卡住 / 超时 | 国内网络 | 换镜像：`-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `npm install` 卡住 | 国内网络 | 换镜像：`--registry=https://registry.npmmirror.com` |
| `bcrypt` 装失败 | macOS 缺命令行工具 | `xcode-select --install` |
| 端口 8000/5173/5174 被占用 | 已有进程 | macOS/Linux: `lsof -i :8000` → `kill -9 PID`；Windows: `netstat -ano \| findstr :8000` → `taskkill /PID xxx /F` |
| MySQL `caching_sha2_password` 报错 | MySQL 9.x 默认插件 | 在初始化命令加 `--default-authentication-plugin=mysql_native_password` |
| `brew services` 报 LaunchAgents 权限 | macOS 沙箱 | 改用前台启动：`mysqld_safe ... &` 和 `redis-server ... &` |
| MySQL 已初始化报错 | 数据目录已存在 | 直接跳过 Step 3 的初始化，启动即可 |
| 学号或密码错误 | seed 没跑 | `python seed.py` |
| AI 聊天报「服务异常」 | DeepSeek key 未配 | 编辑 backend/.env 填 key 后重启后端 |
| Windows PowerShell 不能激活 venv | 执行策略 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 知识库上传报错 | Redis 没启动 | `redis-cli ping` 应返回 PONG |
